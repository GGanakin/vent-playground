# 黄昏的小区游乐场

一个单文件的发泄页面。双击 `index.html` 就能打开，没有依赖、没有网络请求、没有素材文件，声音是浏览器现场合成的。

## 怎么玩

- 点一下踹，按住不放再松开是重踹，空格键也可以。
- 瓶子、易拉罐、皮球按住往上拖可以捡起来，松开就是投出去。
- 垃圾桶能投进去，也能踹翻；头顶那个灯泡只能靠扔上去的东西砸下来。
- 摇椅会一路坏下去，坏到底之后自己看。

右上是静音按钮，也可以按 `M`。

## 说明

- 全部逻辑、绘制和音效都在 `index.html` 里，Canvas 2D + Web Audio。
- 建议用桌面浏览器；手机上拖拽和投掷也能用。
